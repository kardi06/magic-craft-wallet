# Story 6.1: Apply MagicCraft Theme

## Status

Approved
Priority: P0 (Top)

## Story

As a user,
I want the wallet UI to reflect the MagicCraft theme,
so that the experience feels cohesive and on-brand.

## Acceptance Criteria

1. Color palette applied across main UI surfaces (Midnight Blue `#1A1B2F`, Arcane Purple `#6E4B9E`, Gold Accent `#F1C40F`)
2. Spellbook visual touches present on main screens (rounded parchment panels, glowing hover effects, rune-like icons)

## QA Results

- Verdict: AC1 Pass, AC2 Partial. Ready with minor polish.
- Evidence:
  - Colors: `src/app/styles/index.css` defines `--magic-midnight` (#1A1B2F), `--magic-purple` (#6E4B9E), `--magic-gold` (#F1C40F). Base `html, body` apply midnight background and white text.
  - Classes: `.magic-page`, `.magic-card`, `.magic-heading`, `.magic-subtle`, `.btn-magic` (with glow hover/focus) defined in `index.css`.
  - Layouts: `PopupLayout.tsx`, `MainPageLayout.tsx`, `BoardingPageLayout.tsx` apply `magic-page` and `magic-card` to main surfaces.
  - Components: `Button.tsx` supports `theme="magic"`; snapshot test `Button.magic.test.tsx` verifies `btn-magic`.
  - Assets: Favicon wired in `public/main.html` and `public/approve.html` to `/icons/magiccraft/favicon.ico`.
  - Toggle: Settings → General adds `magic` class to root and persists `theme:magic`.
- Checks:
  - Contrast: White text on midnight background and on translucent card surfaces appears compliant for primary text. Buttons maintain sufficient contrast.
  - Screens: Onboarding (via `BoardingPageLayout`), popup, and main pages inherit theme from layouts.
- Gaps/Risks:
  - `bg-magic-parchment`/surface tokens are used in layouts but not found in `index.css`; likely expected from Tailwind config. Could not locate `tailwind.config.js` in repo snapshot to verify.
  - “Rune-like icons” usage is not explicitly verifiable; current icon set is standard app icons.
  - Theme toggle currently only adds a `magic` class; most theming is via explicit `magic-*` classes, so toggle may not disable the theme. Acceptable as a scaffold but note for future.
- Recommendations:
  - Ensure Tailwind theme defines `bg-magic-parchment`, `bg-surface-card`, and `border-surface-border` tokens referenced by layouts.
  - If a true on/off is desired, scope theme under `.magic` or swap classes based on toggle.
  - Introduce at least one rune-like/themed icon or decoration to fulfill AC2 more explicitly.
- Conclusion: Meets brand palette and primary theming (AC1). Visual touches are present (glow, parchment, rounded cards) but iconography is generic (AC2 partial). Approve with minor follow-ups above.
