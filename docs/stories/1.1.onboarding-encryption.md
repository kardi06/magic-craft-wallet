# Story 1.1: Onboarding & Encryption

## Status
Approved

## Story
As a new user,
I want to create or import a 12-word wallet and unlock it with a passphrase,
so that I can securely sign a test transaction.

## Acceptance Criteria
1. Create/import 12-word mnemonic
2. AES encryption at rest, passphrase unlock
3. Encrypted storage in chrome.storage.local
4. Background can decrypt/sign a dummy tx

## Tasks / Subtasks
- [x] Implement mnemonic create/import flow in UI (AC: 1)
  - [x] Add onboarding screen(s) to create or import 12-word mnemonic (bip39)
  - [x] Add passphrase input and confirmation (min length rules if defined)
  - [x] Wire onboarding state to background request messages
- [x] Implement background wallet management (AC: 1, 2, 3)
  - [x] Generate/import mnemonic using bip39
  - [x] Derive wallet using ethers.js
  - [x] AES encrypt mnemonic with user passphrase using WebCrypto
  - [x] Persist encrypted payload + salt in chrome.storage.local
- [ ] Unlock and signing flow (AC: 2, 4)
  - [x] Prompt for passphrase to decrypt mnemonic in background
  - [ ] Create dummy transaction and sign with ethers.js
  - [ ] Return tx hash to UI and display success
- [ ] Network configuration alignment (AC: 4)
  - [ ] Ensure RPC provider selection exists and defaults per architecture
- [ ] Testing
  - [ ] Unit tests for encryption/decryption helpers
  - [ ] Unit tests for storage read/write of encrypted blob
  - [ ] Integration test for create/import → unlock → sign dummy tx
